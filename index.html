Golden rule: Only practise hacking on systems you own or labs built for learning (TryHackMe, Hack The Box, your own virtual machines). Hacking real systems without permission is illegal — ethical hackers always get permission first.

How every lesson works

1. Analogy — the idea in everyday words   2. Watch — a selected video or guided video search   3. Read — a simple explanation   4. Try it — complete all three hands-on steps   5. Quiz — get at least 2 of 3 right. Most lessons take 20–30 minutes; setup and external labs can take longer.

Where this path takes you

Computers → Files → Networking → Linux → How the Web Works → Security Basics → Defending Systems (Blue Team) → Windows Security Deep Dive → Ethical Hacking (Pen Testing) → Reverse Engineering → Practice platforms & certifications (TryHackMe, CompTIA Security+, etc.). At the end you will know what to study next for a real job — and you will already have hands-on practice.

Most lessons include a selected video with verification metadata. Where no video matches the lesson closely (the JavaScript lessons, some Windows lessons and the Arch Linux lessons), the lesson uses guided reading with official sources; video searches are optional. A YouTube search remains available as a fallback if an embed cannot play. Use captions/transcripts when available. Practical lessons also include official tool or lab links where they are needed.
